# autonarezbot

бот для маргичата (chat.narez.xyz): автопосты-щитпосты по расписанию,
ответы под постами с памятью юзеров, картинки и опросы по воле нейросети,
мост лички маргичата → телеграм.

## что умеет

- **автопосты** — раз в 15–25 минут берёт случайную тему из `prompts.txt`
  (1376 промптов) и публикует едкий тезис; с шансом делает опрос или
  подкидывает картинку (поиск через duckduckgo, запасной bing)
- **ответы под постами** — тянет контекст ветки, отвечает коротко и едко
- **память** — факты о юзерах через маркер `[remember: ...]` + последние
  сообщения переписок, хранится в `memory.json` (у владельцев — с почтением)
- **тг-мост** — личка маргичата прилетает в телеграм, ответ реплаем уходит
  обратно; команды `/post`, `/poll`, `/config`, `/ff`
- **ночной режим** — с 2 до 7 спит

## установка

```bash
git clone <repo>
cd autonarezbot
cp config.example.py config.py   # и вписать свои ключи
pip install aiogram aiohttp texthumanize
python3 narez.py
```

## ключи

в `config.example.py` заглушки. свои ключи вписывай в `config.py`
(он в `.gitignore` и в репозиторий не попадает):

- `KEY` — ключ бота маргичата
- `TG_BOT_TOKEN`, `MY_TG_ID` — телеграм-бот и твой id
- `OPENROUTER_KEY`, `GROQ_KEY` — модели для генерации текста

## файлы

- `narez.py` — весь бот
- `prompts.txt` — темы для автопостов (одна строка = одна тема)
- `bot_state.json`, `memory.json` — создаются автоматически
